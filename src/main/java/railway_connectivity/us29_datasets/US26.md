## 2. Efficiency Analysis of US13

User Story 13 aims to check if a train of a specific type (e.g., steam, diesel, electric) can travel from station A to station B, given the limitations of the railway lines (some of which may not support certain train types).

This corresponds to a pathfinding problem in a graph, where the graph is represented by stations (vertices) and railway lines (edges). The algorithm must determine if there exists a path from vertex A to vertex B that adheres to the train type constraints.

### 2.1 Graph Representation

The railway network is modeled as an undirected graph G = (V, E), where:

- V: set of vertices (stations)
- E: set of edges (railway lines), which can be electrified or non-electrified.

### 2.2 Reachability Algorithm

To verify whether the train can travel from station A to station B, the algorithm:

1. Constructs the graph from the list of edges, filtering out those that do not support the train type.
2. Performs a depth-first search (DFS) or breadth-first search (BFS) starting from station A, marking visited stations.
3. Checks if station B is reachable from station A by verifying if it is in the set of visited stations.

### 2.3 Worst-Case Time Complexity

The algorithm performs the following steps:

1. **Graph construction** - `O(E)`: each edge is added to the adjacency list of both connected vertices;
2. **Connectivity using DFS** - `O(V + E)`: explores all vertices and edges at must once in the worst case.

**Overall US13 time complexity: O(V + E)**

### 2.4 Pseudocode

#### a) Connectivity Check (`isConnected`)

This function performs a depth-first search (DFS) starting from a vertex with neighbors, and verifies if all reachable vertices are part of the same connected component.

```
Function isConnected(adjacencyList, vertices):
    visited ← empty set
    nonZeroVertices ← vertices with non-zero degree
    
    If nonZeroVertices is empty:
        Return True
    
    start ← first vertex in nonZeroVertices
    dfs(start, adjacencyList, edges, vertices, visited)
    
    For each vertex in nonZeroVertices:
        If vertex not in visited:
            Return False
    Return True

Function dfs(vertex, adjacencyList, edges, vertices, visited):
    Add vertex to visited
    
    For each edgeIndex in adjacencyList[vertex]:
        edge ← edges[edgeIndex]
        otherVertex ← (edge[0] = vertices[vertex]) ? edge[1] : edge[0]
        otherVertexIndex ← index of otherVertex in vertices
        
        If otherVertexIndex not in visited:
            dfs(otherVertexIndex, adjacencyList, edges, vertices, visited)
```

**Time Complexity**: O(V + E) - each vertex and edge visited at most once


#### b) Path Finding (`findPath`)
This function implements a depth-first search (DFS) to find a path from station A to station B, considering the train type constraints.

```
Function findPath(start, end, adjacencyList, edges, trainType):
    stack ← empty stack
    visited ← boolean array of size vertices.length, initialized to false
    path ← empty list
    
    Push start to stack
    
    While stack is not empty:
        current ← top of stack
        
        If current = end:
            Add current to path
            Return path
        
        If not visited[current]:
            visited[current] ← true
            Add current to path
            
            For each edgeIndex in adjacencyList[current]:
                edge ← edges[edgeIndex]
                
                If edge supports trainType:
                    nextVertex ← (edge[0] = vertices[current]) ? edge[1] : edge[0]
                    Push nextVertex to stack
        Else:
            Pop from stack
            Remove current from path
    
    Return empty list  // No path found
```
**Time Complexity**: O(V + E) - each vertex and edge is processed at most once

## 3. Efficiency Analysis of US14

User Story 14 requires that, given a railway network (represented as a graph with stations and railway lines), the system should verify whether it is possible to find a maintenance route that traverses each railway line exactly once.

This corresponds to detecting the existence of an Eulerian Path (or Eulerian Circuit) in an undirected graph and constructing the actual route.

An Eulerian Path exists in a connected undirected graph if:
- Exactly two vertices have an odd degree (start and end points);
- All vertices have an even degree, in which case an Eulerian Circuit is possible (start and end at the same station).

If the graph is disconnected, or has more than two vertices with odd degree, no Eulerian path is possible.

### 3.1 Graph Representation

The railway network is modeled as an undirected graph G = (V, E), where:
- V: set of vertices (stations)
- E: set of edges (railway lines), which can be electrified or non-electrified.

Depending on the user's selection, the algorithm may consider:
- All the railway lines (electrified and non-electrified);
- Only the electrified ones.

### 3.2 Eulerian Route Construction

The algorithm implements Hierholzer's algorithm to construct the actual Eulerian route:
1. Start from a vertex with odd degree (if exactly 2 exist) or any vertex (if all have even degree)
2. Follow edges, removing them as traversed
3. When stuck, find another vertex with remaining edges and create a cycle
4. Merge cycles to form the complete Eulerian path

### 3.3 Worst-Case Time Complexity

The algorithm performs the following steps:

1. **Graph construction** - `O(E)`: each edge is added to the adjacency list of both connected vertices;
2. **Connectivity using DFS** - `O(V + E)`: verifies that all non-isolated vertices belong to a single connected component;
3. **Counting odd-degree vertices** - `O(V)`: iterates through each vertex to compute its degree;
4. **Eulerian route construction** - `O(E)`: Hierholzer's algorithm traverses each edge exactly once.

**Overall US14 time complexity: O(V + E)**

### 3.4 Pseudocode

#### a) Connectivity Check (`isConnected`)

This function performs a depth-first search (DFS) starting from a vertex with neighbors, and verifies if all reachable vertices are part of the same connected component.

```
Function isConnected(adjacencyList, vertices):
    visited ← empty set
    nonZeroVertices ← vertices with non-zero degree
    
    If nonZeroVertices is empty:
        Return True
    
    start ← first vertex in nonZeroVertices

    For each vertex in nonZeroVertices:
        If vertex not in visited:
            Return False
    Return True

Function dfs(vertex, adjacencyList, edges, vertices, visited):
    Add vertex to visited
    
    For each edgeIndex in adjacencyList[vertex]:
        edge ← edges[edgeIndex]
        otherVertex ← (edge[0] = vertices[vertex]) ? edge[1] : edge[0]
        otherVertexIndex ← index of otherVertex in vertices
        
        If otherVertexIndex not in visited:
            dfs(otherVertexIndex, adjacencyList, edges, vertices, visited)
```

**Time Complexity**: O(V + E) - each vertex and edge visited at most once

#### b) Odd-Degree Vertices Count (`countOddDegreeVertices`)

This function iterates through all vertices in the graph and counts how many have an odd number of connections (degree).

```
Function countOddDegreeVertices(adjacencyList, vertices):
    oddVertices ← empty list
    
    For each vertexIndex from 0 to vertices.length - 1:
        degree ← size of adjacencyList[vertexIndex]
        If degree > 0 and degree mod 2 ≠ 0:
            Add vertexIndex to oddVertices
    
    Return oddVertices
```

**Time Complexity**: O(V) - single pass through all vertices

#### c) Eulerian Route Construction (`findEulerianRoute`)

This function implements Hierholzer's algorithm to construct the actual Eulerian path.

```
Function findEulerianRoute(startVertex, vertices, adjacencyList, edges):
    route ← empty list
    stack ← empty stack
    edgeUsed ← boolean array of size edges.length, initialized to false
    
    Push startVertex to stack
    
    While stack is not empty:
        current ← top of stack
        
        foundEdge ← false
        For each edgeIndex in adjacencyList[current]:
            If not edgeUsed[edgeIndex]:
                edge ← edges[edgeIndex]
                nextVertex ← (edge[0] = vertices[current]) ? 
                            vertices.indexOf(edge[1]) : vertices.indexOf(edge[0])
                
                edgeUsed[edgeIndex] ← true
                Push nextVertex to stack
                foundEdge ← true
                Break
        
        If not foundEdge:
            Add vertices[current] to route
            Pop from stack
    
    Reverse route
    Return route
```

**Time Complexity**: O(E) - each edge is processed exactly once

#### d) Eulerian Path Verification (`hasEulerianPath`)

This function combines connectivity check and odd-degree analysis to determine Eulerian path feasibility.

```
Function hasEulerianPath(adjacencyList, vertices, edges):
    If not isConnected(adjacencyList, vertices):
        Return "No Eulerian path – graph is disconnected"
    
    oddVertices ← countOddDegreeVertices(adjacencyList, vertices)
    oddCount ← size of oddVertices
    
    If oddCount = 0:
        Return "Eulerian circuit possible"
    Else if oddCount = 2:
        Return "Eulerian path possible"
    Else:
        Return "No Eulerian path – " + oddCount + " odd-degree vertices"
```

**Time Complexity**: O(V + E) - dominated by connectivity check
