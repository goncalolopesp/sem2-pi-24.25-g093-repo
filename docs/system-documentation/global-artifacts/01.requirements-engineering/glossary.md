# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

Column "TEA (PT)" is optional. If the team does not intend to use it, then remove it.

(Complete according to the provided example)

| **_TEA_** (EN)          | **_TEA_** (PT)          | **_Description_** (EN)                                                                                                                            |                                       
|:------------------------|:------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| **Building**            | **Edifício**            | A structure that can be added to a station, to upgrade its statistics.                                                                            |
| **Cargo**               | **Carga**               | Materials that are transported by trains, between stations.                                                                                       |
| **Carriage**            | **Carruagem**           | A part of a train that is used to carry either people or freight.                                                                                 |
| **City**                | **Cidade**              | A location in the map that is able to generate various types of cargo, such as passengers and mail, and that can also consume the final products. |
| **Depot**               | **Depósito**            | A small station that costs 50k and has a 3x3 economic radius.                                                                                     |
| **Diesel Locomotive**   | **Locomotiva Diesel**   | A type of locomotive in which the prime mover is a diesel engine.                                                                                 |
| **Double Line**         | **Linha Dupla**         | A type of railway that allows trains to travel in both directions.                                                                                |
| **Editor**              | **Editor**              | A person that can create maps and scenarios.                                                                                                      |
| **Electric Locomotive** | **Locomotiva Elétrica** | A type of locomotive that is powered by electricity, which requires specific electrified lines.                                                   |
| **Farm**                | **Quinta**              | A facility that produces crops.                                                                                                                   |
| **Industry**            | **Indústria**           | A structure that is located on the map that can consume or transform resources. Industries can be primary, transforming or mixed.                 |
| **Line**                | **Linha**               | A track connecting two stations.                                                                                                                  |
| **Locomotive**          | **Locomotiva**          | The engine that provides power to the train. A locomotive can be steam, diesel or electric.                                                       |
| **Map**                 | **Mapa**                | An area/region where cities, industries and stations can be placed. The map also defines the playable area of the simulator.                      |
| **Mixed Industry**      | **Indústria Mista**     | A type of industry that can deal with various types of cargo.                                                                                     |
| **Passenger**           | **Passageiro**          | A type of cargo obtained while playing the simulator.                                                                                             |
| **Player** | **Jogador** | A person that will be able to manage the railway network in the simulator, including building stations, railway lines, and managing trains.       |
| **Primary Sector Industry** | **Indústria do Setor Primário** | An industry that generates raw materials, which can be used by other industries.                                                                  |
| **Product Owner** | **Proprietário do Produto** | A person that demands all the functionalities that need to be avilable on the final product.                                                      |
| **Port**                | **Porto**               | A hub used on the importation and exportation of cargo via waterways.                                                                             |
| **Route**               | **Rota**                | A predetermined course that a train follows.                                                                                                      |
| **Scenario** | **Cenário** | A set of conditions (available on a certain map) that determines the trains that can be used, the time period, available technologies, etc.       |
| **Simulator**           | **Simulador**           | A system that oversees traffic movement and train routes.                                                                                         |
| **Single Line** | **Linha Única** | A type of railway that allows trains to travel in a single direction.                                                                             |
| **Station**             | **Estação**             | A designated stop where people and freight are able to enter/leave the train.                                                                     |
| **Steam Locomotive**    | **Locomotiva a Vapor**  | A type of locomotive that produces its pulling power through a steam engine.                                                                      |
| **Terminal**            | **Terminal**            | A major station that has more services than a normal station.                                                                                     |
| **Train**               | **Comboio**             | A powered vehicle used for transporting people or freight on railways.                                                                            |
| **Transforming Industry** | **Indústria Transformadora** | An industry that transforms raw materials into finished products.                                                                                 |
